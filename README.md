# Misbah — аят дня на экране блокировки

Нативное iOS-приложение (Swift 6, SwiftUI, WidgetKit): один аят Корана в день на экране блокировки, рабочем столе,
в StandBy и в уведомлении. Арабский оригинал над переводом, интерфейс на английском, русском и арабском (справа налево).
«Misbah» — «светильник»: образ из аята Ан-Нур (24:35).

Сделано на основе кода приложения Lampada (нативный виджет со стихами): движок, виджеты, онбординг, пейволл остались,
контент, графика, тексты интерфейса и бренд заменены.

## Что внутри

| Папка | Что |
|---|---|
| `LampadaCore/` | Swift-пакет: `LampadaCore` (движок, корпус, строки), `LampadaUI` (экраны), `LampadaWidgets`, `LampadaPurchases` (RevenueCat) и тесты |
| `App/` | Таргеты приложения и виджета, `make_project.py` собирает `Misbah.xcodeproj` |
| `corpus-src/` | Исходные тексты Tanzil (арабский), Pickthall, Саблуков; лицензия шрифта |
| `tools/corpus/` | Сборка корпуса из исходников с обратной сверкой |
| `tools/i18n/` | Строки интерфейса (ru, en, ar) → `Strings.swift` |
| `tools/art/` | Сборка фонов, иконок и картинок онбординга в каталоги ассетов |
| `art-src/` | Исходные изображения для `tools/art` |
| `design/` | Макеты (Pencil), экспорт картинок |
| `docs/` | `FIRST-BUILD.md` — сборка и выпуск, `TRANSLATIONS.md` — тексты и лицензии, `legal/misbah/` — политика, условия и поддержка (en, ru, ar; собираются `tools/legal/build_legal.py`) |

## Проверка

* Тесты пакета: `cd LampadaCore && swift test` (нужен macOS; на другой платформе тесты интерфейса не соберутся).
* Каждый пуш в `main` проверяет GitHub Actions (`.github/workflows/ci.yml`): тесты пакета, сборка пакета под iOS,
  сборка приложения с виджетом. Логи публикуются в ветку `ci-logs`.
* Корпус: `python tools/corpus/build_corpus.py` (пересобирает `corpus-*.json` и падает, если хоть один аят расходится с источником).
* Строки: `python tools/i18n/gen_strings.py` (пересобирает `Strings.swift`).

## Языки и тексты

Арабский текст — Tanzil Project (CC BY 3.0, без изменений). Переводы — Пикталл (en, 1930) и Саблуков (ru, 1878),
общественное достояние. Подробности, лицензии и почему нет других языков — `docs/TRANSLATIONS.md`.
