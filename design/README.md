# design/

`islampada-design.pen` — копия макета Lampada, переработанная под ислам (редактировать только через Pencil MCP).
Переработано: онбординг ОБ2 00–08, экраны приложения, витрина RU и EN (01–07, 05b, 07b), картинки-фоны (generated*.png).
Не тронуто: ряды DE/FR/ES (тексты ещё христианские), старый онбординг v1 (01–05), красные пометки.
Рабочее название «Nur» — заглушка. Аяты и переводы в макетах — плейсхолдеры, финальный текст соберёт пайплайн корпуса.
