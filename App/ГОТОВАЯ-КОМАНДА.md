# Готовая быстрая команда «Пауза Lampada»

Файл `Пауза Lampada.shortcut` пересобирается командой:

```
python3 make_shortcut.py
```

Внутри одно действие — **«Пауза со стихом»** из App Intents.

## Поле «Приложение» надо заполнить, иначе возврата не будет

У действия есть параметр «Приложение». Из него берётся адрес, по которому
Lampada возвращает человека в соцсеть по кнопке «Продолжить».

Подставить его заранее нельзя: соцсеть выбирает сам человек, а API, который
сказал бы, какую именно он открывает, не существует. Поэтому в готовой команде
поле пустое, и его обязательно надо заполнить — своей копией команды на каждую
соцсеть либо прямо в автоматизации.

Поле обязательное и показано прямо в плитке действия — «Пауза со стихом перед
Instagram», — как у one sec, где рядом с ним стоит пометка «must be selected».
Пока оно было необязательным и не входило в сводку, «Команды» прятали его под
«Показать больше»: в плитке стояло одно название, поле никто не находил, и
«Продолжить» вело в никуда.

Возврат в соцсеть по её адресу автоматизацию заново не поднимает: триггер
«когда открывается приложение» реагирует на открытие человеком, а не на
программное. Поэтому и у one sec нет зацикливания.

## Системного «Открыть приложение» здесь больше нет

Оно стояло вторым действием, пока возврат делали им. До него не доходило дело:
«Команды» убивали наше действие по таймауту раньше — отсюда и «Сбой
автоматизации». Возврат теперь делает само приложение.

## Почему файл подписан

iOS отказывается импортировать неподписанные команды дословной формулировкой
«Импорт неподписанных быстрых команд не поддерживается». Прежней лазейки с
«Ненадёжными быстрыми командами» в настройках больше нет. Генератор подписывает
файл через `shortcuts sign --mode anyone` — без этого режима он открылся бы
только на том компьютере, где создан.

Проверено на симуляторе: неподписанный файл iOS отвергает, подписанный
открывает лист установки и ставит команду с обоими действиями.

## Как получить iCloud-ссылку

Ссылку вида `icloud.com/shortcuts/<id>` выдаёт Apple в момент, когда командой
делятся с устройства, — сгенерировать её из проекта нельзя. Порядок такой:

1. Перенести `Пауза Lampada.shortcut` на iPhone (AirDrop или «Файлы»).
2. Открыть файл → «Добавить».
3. В «Командах» открыть её → «Поделиться» → «Скопировать ссылку iCloud».

Полученную ссылку можно положить в приложение и открывать по кнопке из
инструкции — тогда команда ставится в один тап, без поиска действия вручную.

## Чего это всё равно не решает

Автоматизацию — «когда открыто приложение» — программно создать нельзя, такого
API у Apple нет. Шаг, где человек выбирает соцсеть и создаёт автоматизацию,
остаётся ручным при любом раскладе. Так же устроен и one sec.

## ⚠️ Схема изменилась 2026-09-09 — этот документ описывает прежнюю

Готовая команда собиралась под автоматизацию из **двух** действий: наше
«Пауза со стихом» плюс системное «Открыть приложение». Наше действие при этом
не возвращалось, пока человек не нажмёт «Продолжить», — чтобы возврат случился
после паузы, а не до неё.

Так делать нельзя. «Команды» убивают действие, не уложившееся в отведённое
время (на практике порядка пятнадцати секунд), и на устройстве это дало сразу
три поломки: «Сбой автоматизации», неработающий возврат — до второго действия
дело не доходило — и зацикливание, потому что окно тишины записывалось только
по кнопке.

**Сейчас действие одно, а соцсеть указывается его параметром**, и возврат
делает само приложение по адресу вида `instagram://`. Так же устроен one sec.
Готовая команда под эту схему не помогает: параметр всё равно свой на каждое
приложение, и добавить действие напрямую и короче, и понятнее. Поэтому
`Surface.readyShortcut` сейчас пуст, а кнопки «Поставить готовую команду» нет.

Скрипт и файл оставлены на случай, если схема снова поменяется.
