# Lampada 1.0.2 — проверка в TestFlight

Сборка: `main`, коммит `85957ef` или новее (в нём исправлен краш на запуске).
Отмечай `[x]`; что не так — скриншот и номер пункта.

## Подготовка

Нужны два сценария, на одном телефоне — по очереди:

- **Обновление** (для «Что нового»): поставить Lampada 1.0.1 из App Store,
  пройти онбординг, поставить виджет на экран блокировки, потом обновить
  через TestFlight.
- **Чистая установка** (для онбординга v3): удалить приложение и поставить
  из TestFlight. Вариантов у вопроса «Что тебе сейчас нужнее?» четыре, у
  каждого свой экран ветки и свой пейволл — значит, четыре переустановки.
  После удаления iOS заново спросит про уведомления.

Язык — русский; один проход стоит сделать на английском, чтобы увидеть
переносы в длинных строках.

Без ключей Meta и Amplitude в этой сборке **нет** шага ATT и событий в
Meta/Amplitude — это ожидаемо, их проверим отдельной сборкой.

## 0. Запуск

- [ ] Приложение открывается, не падает. Второй запуск — тоже.

## 1. «Что нового» — сценарий обновления

- [ ] После обновления экран появляется сам, один раз.
- [ ] Сверху три точки (или две, если уведомления раньше запретили) и
      крестик; страницы листаются свайпом.
- [ ] **Иконки:** тап по «Голубю» — iOS показывает «Иконка изменена», на
      рабочем столе Голубь.
- [ ] Тап по платной (Витраж, Крест, Рождество, Пасха) — пейволл с плашкой
      «Твой выбор · …»; закрыл — иконка не меняется.
- [ ] **Картинки:** четыре плитки; тап — предпросмотр на весь экран со
      стихом на сегодня. Стих читается на всех четырёх.
- [ ] В предпросмотре без Pro — «Включить с Pro» ведёт на пейволл.
- [ ] **Стих каждый день:** если про уведомления не спрашивали — кнопка
      «Присылать стих каждый день» вызывает системный вопрос; если уже
      разрешено и стих дня включён — кнопка «Готово».
- [ ] В подзаголовке стоит твоё время стиха дня («в 08:00» или выбранное).
- [ ] Переключатель «Новости и обновления» по умолчанию выключен.
- [ ] «Пропустить» на 1-й и 2-й странице листает к уведомлениям; крестик
      закрывает весь экран.
- [ ] После закрытия и перезапуска экран больше не появляется.
- [ ] **Голубь остаётся** после перезапуска приложения (раньше слетал бы).

## 2. Онбординг v3 — чистая установка

### Общий путь

- [ ] **Стих на сегодня:** лампа ниже, чем в 1.0.1; надпись «СТИХ НА
      СЕГОДНЯ» без даты; язык — строкой со стрелкой, по тапу лист языков;
      внизу «Без аккаунта · без рекламы · работает офлайн».
- [ ] **Что нужнее:** четыре варианта с иконками из глины; «Дальше» не
      нажимается, пока не выбран ответ; полоса прогресса — 1 из 5.
- [ ] Экран ветки — см. ниже, по одной ветке на установку.
- [ ] **Первый стих:** «Прислать первый стих» → системный вопрос → «Разрешить»
      → через ~2 с сверху приходит баннер со стихом на сегодня, заголовок
      меняется на «Первый стих уже пришёл ↑», время в тексте верное.
- [ ] То же с «Не разрешать» — онбординг просто идёт дальше.
- [ ] **Иконка:** 12 иконок, четыре в ряд. Голубь и Основная меняются сразу;
      по платной — подпись «… · Pro», иконка не меняется; «Оставить
      основную» возвращает основную.
- [ ] **Виджет:** «Показать, как поставить» → инструкция. Выйти, поставить
      виджет на экран блокировки, вернуться — экран сам сменяется на
      «Готово». (Второй путь: «Поставил» в инструкции.)
- [ ] «Поставлю позже» — сразу «35 000 раз», без «Готово».
- [ ] **Готово:** большая лампада с искрами, «✓ ВИДЖЕТ НА МЕСТЕ».
- [ ] **«35 000 раз»** → пейволл своей ветки (шага ATT нет — ключей Meta ещё
      нет).
- [ ] **Пейволл:** цены загрузились, две первые плитки светлые, остальные
      обведены; «Не сейчас» закрывает.
- [ ] Закрыл пейволл без покупки — экран скидки с лампадой в ленте
      «Первый год Pro — за $17.49»; «Нет, спасибо» → главный экран.
      Показывается только тому, кому Apple даст вводную цену: если с этого
      Apple ID уже брали триал или скидку, экрана не будет — это нормально,
      переустановка не сбрасывает.
- [ ] После онбординга «Что нового» **не** появляется.

### Ветки

- [ ] **Утешение:** чипы тем; внизу «Выбрано N · нашли M стихов» с
      правильными формами («21 стих», «22 стиха», «214 стихов»). Пейволл:
      «ПОД ТО, ЧТО НА СЕРДЦЕ», плашки — выбранные темы (до четырёх),
      «Слово рядом, когда тяжело», первые плитки StandBy и картинки.
- [ ] **Каждый день:** баннер-превью, колесо времени; «Каждый день в
      HH:MM» запоминает время (его же видно на шаге «Первый стих»);
      «Решу позже» оставляет 08:00. Пейволл: «КАЖДЫЙ ДЕНЬ В HH:MM»,
      плашки «Стих дня» и «Экран блокировки», «Стих везде, куда ты смотришь».
- [ ] **Меньше ленты:** песочные часы, четыре варианта; после ответа внизу
      «≈ N дней в году…» (2–4 часа → 45 дней, 1–2 часа → 22 дня). Пейволл:
      «ПАУЗА — БЕСПЛАТНО НАВСЕГДА», «Меньше ленты — больше Слова».
- [ ] **Красиво:** предпросмотр виджета меняется по тапу; ряд картинок
      листается, новые четыре с замком. Выбери платную картинку и на шаге
      иконки — платную иконку. Пейволл: «ТВОЙ ВЫБОР», плашки иконки и
      картинки, «Сделай его своим», «…8 шрифтов и 10 иконок». Без платного
      выбора — без плашек, подзаголовок «С Pro — все наборы…».
- [ ] **Красиво + покупка** (песочница TestFlight, денег не списывает):
      оформить триал на пейволле — выбранные иконка и картинка встают сами.

## 3. Приложение после онбординга

- [ ] **Вид → Изображение:** 12 картинок; Галилея, Звезда, Гефсимания, Крест
      с замком без Pro.
- [ ] Стих читается на новых фонах — в приложении («Сегодня»), в виджетах
      малом/среднем/большом и в StandBy. **Особенно Звезда и Крест.**
- [ ] **Вид → Иконка приложения:** 12 иконок, бесплатные — Основная и
      Голубь.
- [ ] **Места → В моменте:** строка «Новости и обновления» с переключателем;
      включение без разрешения на уведомления сначала спрашивает систему;
      состояние совпадает с переключателем на «Что нового».
- [ ] «Стих дня в уведомлении»: поставить время на 2–3 минуты вперёд —
      уведомление приходит, по тапу открывается приложение.
- [ ] **Вид:** строка «Оценить Lampada» открывает страницу отзыва в App Store
      (системное окно оценки в TestFlight не появляется никогда — это
      нормально).
- [ ] Регрессия: «Сегодня» листается, «Кто это говорит и когда», «Поделиться»
      (три формата), смена языка и издания, пауза перед лентой из «Мест».

## 4. Рассылки Firebase

- [ ] **Вид** → вкладка «Приложение» → в самом низу строка «Lampada 1.0.2
      (NN)» → зажать её на секунду → вместо версии на 6 секунд появляется
      «Токен уведомлений скопирован». Если вместо этого «APNs: нет · …» —
      пришли скриншот: Apple не выдала телефону токен пушей, дело в подписи.
- [ ] Без токена: Firebase → Messaging → New campaign → Notifications →
      Target: приложение Lampada + условие «Version» = 1.0.2 (эта версия
      есть только у тестировщиков) → Scheduling: Now → Additional options →
      Custom data → Review → Publish. Приходит в течение нескольких минут.
- [ ] Firebase → Messaging → New campaign → Notifications → «Send test
      message», вставить токен; в Additional options → Custom data:
      `tab` = `look`, `paywall` = `1`. Пуш приходит, тап открывает «Вид» и
      пейволл. Это первая проверка боевых пушей Apple на сборке из
      TestFlight.

## 5. Аналитика (GA4 → Отчёты → В реальном времени)

Через 1–2 минуты после действий:

- [ ] `onboarding_step` с параметром «Шаг онбординга» (verse, goal, …).
- [ ] `onboarding_answer` — «Вопрос» goal, «Ответ» — выбранная ветка.
- [ ] `paywall_view` с «Вариантом пейволла» (comfort / daily / feed / beauty).
- [ ] `whats_new_step` и `promo_optin` — в сценарии обновления.

- События в Meta Events Manager (смотреть «Обзор», не «Тестирование
  событий»).
- Amplitude: пользователи и сессии.
