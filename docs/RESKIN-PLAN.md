# islampada — план рескина (Lampada → исламские аяты)

Основа — код Lampada (нативный Swift, виджеты). Функционал почти не меняем.
Меняем: контент (аяты + переводы), графику, онбординг, ASO.

## 0. Решения, без которых не стартуем
1. **Название/бренд.** Идея «светильник» сохраняется через Аят ан-Нур (24:35).
   Кандидаты: Nur, Misbah, Mishkat, Ayah — проверить в Astro и в App Store.
2. **Арабский оригинал** показываем рядом с переводом (иначе перевод — «толкование смысла», а не Коран).
   Это единственное функциональное изменение: поле `arabic` в `Card`, RTL, шрифт Uthmani (Amiri Quran / Scheherazade, OFL),
   переключатель «показывать арабский» (в виджете экрана блокировки — только перевод).
3. **Объём V1.0:** сколько языков сразу (оригинал выходил с 5). Остальные — волнами.
4. **Вычитка мусульманином:** отбор аятов, темы, строки контекста.

## 1. Переводы и языки (главный риск — лицензии)
Принцип: брать только то, что можно коммерчески распространять в приложении; на каждый перевод — запись в матрице
(источник, лицензия, условия, строка авторства). Текст не правим и не набираем руками — только скрипт из источника.

Источники (проверено поиском 09.11, детали на каждый перевод перепроверять):
- **Арабский текст — Tanzil:** CC BY 3.0, копировать дословно, ссылка на Tanzil обязательна.
- **Переводы Tanzil:** источники расходятся — часть пишет «только некоммерческое». Считать риском до проверки каждого перевода.
- **QuranEnc.com** (Rowwad): десятки языков, API; условия — без изменений текста, ссылка на издателя и источник,
  у части изданий доп. условия (номер версии, обновления). Явного разрешения на коммерческое приложение не нашёл — уточнять у издателя письмом.
- **Общественное достояние (проверенно надёжные):** Pickthall (en, 1930), Yusuf Ali (en, 1934), Rodwell, Sale, Palmer;
  русские дореволюционные/ранние (Саблуков 1878; Крачковский — срок и публикацию проверить). Кулиев, Sahih International — защищены.
- Для языков без PD-перевода: письмо издателю/переводчику за разрешением; без ответа — язык не берём.

Шаги: (a) матрица лицензий по всем кандидатам, (b) выбор языков по рынкам (ar, en, ru, tr, id, ms, ur, bn, fr, de, es, pt, + далее),
(c) для каждого — скрипт загрузки и проверка полноты/нумерации (у разных изданий разный счёт аятов, особенно басмала).

## 2. Корпус
- Заменить `build-bundle.py` (eBible) на пайплайн: Tanzil/QuranEnc → карточки `{id, sura:ayah, theme, arabic, text, ref}`.
- Отбор ≈ 450 аятов под 16 состояний (как в оригинале: тревога, утрата, благодарность, прощение, сомнение, начало дела,
  бессонница, вина, доверие, любовь, надежда, немощь, одиночество, решение, страх, усталость). Выбираем только ссылки;
  тексты тянутся из источников, не пишутся мной.
- Предпочитать короткие аяты (лимит экрана блокировки); длинные — только целиком по аяту, без обрезки посреди смысла.
- Строка контекста (≤34 слов): мекканская/мединская, к кому обращено, повод откровения — только общеизвестные факты, без толкования.
  Вычитка обязательна.
- Проверки в сборке: все карточки есть на всех языках, нет обрывков, ссылки сверены с эталоном.

## 3. Код (минимум)
- `Card.arabic`, RTL-вёрстка, шрифты — Today, виджеты, шаринг, пауза, обои.
- `AppLocale` — новые языки; строки интерфейса (~720 ключей × N языков) — самая большая трудоёмкость, делать партиями.
- Удалить/переписать упоминания Библии, Псалмов, Христа (≈45 файлов), тесты корпуса.
- Бренд-идентификаторы: bundle ID, App Group, RevenueCat, Firebase, Codemagic — свои (ключей оригинала в репо нет).
- Pro остаётся только на оформлении и поверхностях; **текст Корана всегда бесплатный**.

## 4. Графика (по макету `lampada-app-design.pen`)
- Фоны (12) — только нефигуративные: геометрический орнамент, каллиграфия, купола и минареты в силуэте,
  пустыня на рассвете, звёздное небо, сад, мозаика. Никаких изображений людей и пророков.
- Палитры/наборы цветов, 12 иконок приложения, лампа → фонарь/светильник из Ан-Нур, иконки онбординга.
- Способ: орнаменты процедурно (Python), атмосферные сцены — генерацией (инструмент выбрать), апскейл как в `build-art.py`.
- Скриншоты стора: берём 7 кадров из .pen («Витрина 01–07» + EN/DE/FR/ES), заменяем стихи, фоны, палитру, тексты;
  на каждый язык.

## 5. Онбординг
Текущий (v3): стих → цель → ветка → первый стих пушем → иконка → виджет → «почему» → ATT → пейволл → скидка.
Улучшать после разбора воронки и сообщения куратора. Первые идеи: короче до пейволла, арабский + перевод на первом экране,
выбор языка перевода в начале, превью виджета на реальных обоях пользователя.

## 6. ASO (Astro MCP)
Astro работает на Mac (127.0.0.1:8089) — нужен доступ. Шаги: ключи (quran widget, ayah of the day, islamic wallpaper…)
по рынкам, конкуренты (Muslim Pro, Quran Majeed, виджет-приложения), названия/подзаголовки по локалям,
скрипт `build-metadata.py` как источник текстов.

## 7. Индуизм (после Корана)
Ядро — Бхагавад-гита (санскрит + переводы XIX в. в PD: Arnold, Besant, Telang), затем Упанишады (Müller, SBE), Ригведа (Griffith),
Рамаяна/Махабхарата (Griffith, Ganguli). Те же матрица лицензий и пайплайн.

## Порядок
Лицензии/языки → название → форк-чистка → пайплайн корпуса → код (арабский) → графика → строки интерфейса →
онбординг → скриншоты → ASO → сборка в Codemagic → TestFlight.
